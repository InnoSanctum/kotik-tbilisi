# Сайт помощи коту Котику (Тбилиси) / Help Kotik Website

Страница сбора средств на лечение дворового кота Котика в Тбилиси.
Статический сайт без сборки и без фреймворков — работает на GitHub Pages как есть.

## Особенности

- **3 языка**: русский, английский, грузинский. Выбор сохраняется в браузере,
  при первом визите берётся язык браузера.
- **Галерея на манифесте**: список фото/видео лежит в `media.js`,
  добавление нового файла — одна запись в списке, HTML трогать не нужно.
- **Адаптивный UI**: проверено на 360 / 390 / 700 / 850 / 1100 / 1440 px.
- **Лёгкие фото**: WebP, ~830 КБ на первую загрузку вместо 3.7 МБ за одно фото.
- **Подтверждающие документы**: анализ крови и заключение ветклиники ZooFamily.

## Структура

```
index.html          вся страница: разметка, стили, переводы
media.js            что показывать в галерее  <- редактируется чаще всего
media/              фото 1600px WebP
media/thumbs/       превью 400x400 WebP
assets/gallery.js   загрузчик галереи
assets/author.webp  фото автора в блоке «Об авторе» (600x600)
assets/             иконки, стрелки, QR-код, документы
tools/              вспомогательные скрипты (в сайт не входят)
```

Блок «Об авторе» (имя, описание, контакты) правится прямо в `index.html`:
текст — в таблице `translations` по ключам `authorTitle`, `authorName`,
`authorBio`; ссылки на почту, Telegram и Instagram — в разметке
`.author-contacts`. Заменить фото:

```bash
python -c "from PIL import Image, ImageOps; im=ImageOps.exif_transpose(Image.open('new.jpg')).convert('RGB'); ImageOps.fit(im,(600,600),Image.LANCZOS,centering=(0.5,1.0)).save('assets/author.webp','WEBP',quality=82,method=6)"
```

## Как добавить фото

1. Сожмите исходник (нужен Python + Pillow: `pip install Pillow`):

   ```bash
   python tools/build_media.py "C:\путь\к\20260801_123456.jpg"
   ```

   Скрипт сам развернёт фото по EXIF-ориентации, уменьшит до 1600px,
   сделает превью 400×400 и **удалит все метаданные** — включая GPS-координаты
   и модель телефона. Имя файла берётся из даты съёмки: `kotik-2026-08-01.webp`.

2. Допишите один объект в `media.js` (не забудьте запятую после предыдущего):

   ```js
   {
     "type": "image",
     "src": "media/kotik-2026-08-01.webp",
     "thumb": "media/thumbs/kotik-2026-08-01.webp",
     "alt": { "ru": "Котик во дворе", "en": "Kotik in the courtyard", "ka": "კოტიკი ეზოში" }
   }
   ```

3. Проверьте, что ничего не сломалось:

   ```bash
   python tools/check_site.py
   ```

   Скрипт найдёт опечатку в `media.js`, несуществующий файл и забытый перевод
   и покажет номер строки.

> **Важно.** Первое фото из `media.js` продублировано прямо в `index.html`
> (тег `<img>` и `<link rel="preload">`) — чтобы оно начало грузиться сразу,
> одновременно со страницей. Если вы поменяете **первый** элемент
> списка, поправьте эти две строки в `index.html`.
> `check_site.py` об этом предупредит.

## Как добавить видео

В `media.js` поддерживаются три типа записей:

```js
{ "type": "image",   "src": "media/x.webp", "thumb": "media/thumbs/x.webp", "alt": {…} }
{ "type": "video",   "src": "media/x.mp4",  "thumb": "media/thumbs/x.webp", "alt": {…} }
{ "type": "youtube", "id":  "VIDEO_ID",     "thumb": "media/thumbs/x.webp", "alt": {…} }
```

Превью (`thumb`) нужно и для видео — оно же показывается вместо плеера,
пока никто не нажал play. Сделать его можно тем же `build_media.py`
из любого кадра ролика.

**Видео лучше не класть в репозиторий.** Git хранит все версии файлов навсегда:
один раз перезалить ролик на 50 МБ — значит навсегда добавить 100 МБ к весу
репозитория, а у GitHub Pages есть мягкий лимит около 1 ГБ на сайт.

Для уличных выступлений практичнее всего **YouTube (можно «по ссылке»,
не публично)** — бесплатно, сам подстраивает качество под скорость связи.
Плеер вставляется «фасадом»: сначала показывается только картинка-превью,
а настоящий iframe (около 1 МБ скриптов и куки) грузится **только** после
клика по кнопке play. Домен — `youtube-nocookie.com`.

Если всё же хостить видео самостоятельно: H.264 + AAC, не выше 1080p,
битрейт ~2.5 Мбит/с, обязательно `-movflags +faststart` и превью в `thumb`.

## Локальный просмотр

Просто откройте `index.html` двойным кликом — галерея работает полностью,
сервер не нужен.

Именно поэтому список лежит в `media.js`, а не в `media.json`: браузеры
запрещают читать локальные файлы через `fetch`, и с JSON-файлом галерея
при открытии с диска показывала бы только одно фото.

## Публикация на GitHub Pages

1. Загрузите файлы в репозиторий.
2. **Settings** → **Pages**.
3. Ветка `main`, папка `/ (root)`, **Save**.

## Управление галереей

- Стрелки на фото, клик по превью.
- Стрелки `←` / `→` на клавиатуре — когда галерея в фокусе.
- Свайп пальцем влево/вправо на телефоне.
