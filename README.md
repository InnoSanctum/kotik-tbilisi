# Сайт помощи коту Котику (Тбилиси) / Help Kotik Website

Страница сбора средств на лечение дворового кота Котика в Тбилиси.

## Особенности
- **3 языка**: Русский, Английский, Грузинский (мгновенное переключение).
- **Адаптивный современный UI**: Удобно смотреть как с телефона, так и с компьютера.
- **Подтверждающие документы**: Анализ крови и заключение ветеринара ZooFamily прикреплены в формате PDF.
- **Интерактивная галерея**: Главное фото + QR-код для перевода с возможностью дополнения.
- **Готов к публикации**: Подходит для **GitHub Pages** и **Vercel**.

## Быстрая публикация на GitHub Pages:
1. Создайте репозиторий на [GitHub](https://github.com/new).
2. Распакуйте архив и загрузите все файлы в репозиторий.
3. Зайдите в **Settings** -> **Pages**.
4. Укажите ветку `main` и папку `/ (root)`, нажмите **Save**.
5. Сайт опубликуется за 1 минуту!
